Asked what would help, the participant asks for data provenance: a link to the source of each number or the date of the last sync. The request is stated once, in answer to a direct question, and is modest in scope - visibility rather than a new feature set.

> "Honestly, seeing where each number comes from. Just a link to the source, or the date of the last sync."
> - Claire Martin, [[interview-claire-martin]]
